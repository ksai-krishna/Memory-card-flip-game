2.1 Introduction 
Cloud computing has significantly transformed the development and deployment of modern web 
applications by providing scalable, reliable, and cost-effective infrastructure. Organizations and 
educational institutions increasingly use cloud platforms such as Microsoft Azure to host 
applications, ensuring high availability, secure access, and simplified maintenance. Along with 
cloud hosting, version control systems like GitHub and DevOps practices have become essential 
for collaborative software development and automated deployment. 
Event management systems are widely used to organize conferences, workshops, seminars, 
technical fests, and cultural p rograms. Traditional event management methods often rely on 
manual registration and static web pages, which are difficult to maintain and update. Cloud-based 
event management portals address these challenges by offering centralized access to event 
information, online registration, and automated deployment through cloud platforms. 
This chapter reviews existing research related to cloud computing, Microsoft Azure, GitHub-based 
version control, and web -based event management systems. It discusses their methodo logies, 
advantages, limitations, and identifies the research gap that motivated the development of the 
proposed Cloud-Based Event Management Portal using Microsoft Azure and GitHub.

CONCLUSION AND FUTURE SCOPE 
 
 
The Cloud-Based Event Management Portal using Microsoft Azure and GitHub was successfully 
designed, developed, and deployed as a responsive web application that simplifies the process of 
managing events and participant registrations. The application provides users with an intuitive 
interface to browse upcoming events, view schedules, and register online while demonstrating the 
practical implementation of cloud computing technologies. The integration of GitHub with Azure 
DevOps Pipelines enables Continuous Integration and Continuous Deployment (CI/CD), ensuring 
that every code update is automatically built and deployed to Microsoft Azure App Service. The 
project achieves its objectives by providing a reliable, scalable, and user -friendly cloud-based 
event management solution. 
 
The developed application demonstrates how cloud services can improve application accessibility, 
deployment efficiency, and maintainability. By utilizing Microsoft Azure for hosting and GitHub 
for version control, the project reduces manual deployment efforts and ensures that the latest 
version of the application is always available to users. The responsive design allows the portal to 
be accessed from various devices, making it suitable for educational institutions, organizations, 
and event organizers. Overall, the project provides a practical example of integrating modern web 
technologies with cloud computing services to develop an efficient event management system. 
 
In the future, the Event Management Portal can be enhanced by integrating cloud databases such 
as Azure SQL Database to store participant and event information, implementing user 
authentication and administrator dashboards, and adding email or SMS notifications for event 
updates. Additional features such as online payment gateways, QR code -based event passes, 
analytics dashboards using Microsoft Power BI, AI-based event recommendations, and a dedicated 
mobile application can further improve the functionality and usability of the system. These 
enhancements would make the portal more secure, scala ble, and suitable for real -world event 
management application.
